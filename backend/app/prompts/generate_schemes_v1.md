# 任务

基于项目目标、项目长期知识、用户想法，以及检索得到的场景启发和算法启发，生成三个结构明显不同的候选研究方案。

如果输入包含 validation_feedback，说明上一组候选未通过验证；新候选必须逐项回应这些反馈，
不能只改名或复述原方案。

# 强制规则

- 只输出 CandidateSet，且必须恰好包含三个方案。
- 三个方案必须在核心场景、模型变化或算法路线中至少有一项实质不同，不能只是改名。
- 将输入知识当作启发素材，不要复制原论文表述，也不要输出来源类型、证据 ID 或引文。
- 明确解释场景与算法为何能够组合，以及组合后解决了什么新问题。
- 不得声称未经验证的首创性；novelty_risk 必须保持审慎。
- 严格遵守项目排除项和用户目标中的明确硬约束。
- 只描述宽泛场景、模型和算法创新，不生成完整公式、完整约束或算法代码。
- simple_combination_risk、compatibility_risks 和 unresolved_questions 不得省略。
